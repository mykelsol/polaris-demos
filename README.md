# Polaris Demos

This repository hosts self-contained HTML demos for Polaris decision workflows.

## 360 Logistics (4PL Control-Tower)
Live: https://mykelsol.github.io/polaris-demos/360-logistics/

Included flows:
- Operations Dashboard () — KPIs and links into flows
- Cargo Tracking — filters, status transitions, Exceptions (customs/port/NOTAM/closures)
- Aviation Scheduling — multi‑day tabs, new‑flight modal, Exceptions overlay
- 360 Logistics Decision Hub — same feel as the prior Contested Logistics hub
- Carrier Tendering — 4PL tender board (Decision Case: )
- Billing & Reconciliation — invoice discrepancy handling (Decision Case: )

Decision governance pattern:
- Non‑compensating gates (e.g., authority, feasibility, freshness)
- Bounded options (Verify / Prepare / Hold / Award / Approve‑Adj / Reject)
- Evidence lineage and immutable audit (Decision‑Time vs Outcome)

Local usage: clone the repo and open  in a browser.
